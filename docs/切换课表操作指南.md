# 切换课表操作指南

## 功能说明

课表页右上角新增“切换课表”按钮，用于在多份课表之间快速切换。每份课表独立保存以下内容：

- 课表名称
- 课程列表
- 学期开始日期
- 课表周数与每天节数设置
- 最近一次导入的文件名与解析提示

当前课表会在按钮上显示名称；切换后，课表网格、周次、课程数量和日期会一起更新。

## 使用流程

### 1. 打开课表列表

1. 进入“课表”页面。
2. 点击右上角的“切换课表”按钮。
3. 在弹出的课表列表中查看已经保存的课表。
4. 当前正在使用的课表会显示选中状态。

### 2. 切换到另一份课表

1. 在列表中点击目标课表名称。
2. 弹窗关闭后，课表页会显示目标课表。
3. 当前周次会保留在目标课表允许的范围内；如果超出范围，则自动调整到目标课表的最后一周。

### 3. 新增一份课表

1. 打开右上角“切换课表”。
2. 点击“新增课表”。
3. 输入课表名称并确认。
4. 切换到新课表后，进入“导入”页面导入文件，或直接点击空白格手动添加课程。

新课表不会覆盖其他课表的数据。

### 4. 重命名课表

1. 打开课表列表。
2. 点击目标课表右侧的“更多”按钮。
3. 选择“重命名”。
4. 输入新名称并保存。

### 5. 删除课表

1. 打开课表列表。
2. 点击目标课表右侧的“更多”按钮。
3. 选择“删除”。
4. 在确认提示中确认删除。

删除前请确认课表中没有需要保留的课程。至少保留一份课表时，最后一份不能删除。

## 导入课表时的注意事项

- 导入页面默认将数据写入当前选中的课表。
- 导入前请确认右上角显示的是目标课表，避免把文件导入错误的课表。
- 如果希望保留原课表，请先通过“新增课表”创建副本，再进行导入。
- 导入仍会经过预览和确认，确认前不会覆盖当前课表内容。

## 常见问题

### 切换后课程数量不对

确认当前显示的课表名称是否正确，再检查周次输入框。不同课表的课程和周数互相独立。

### 删除按钮不可用

当前版本至少保留一份课表，不能删除最后一份。可以先新增另一份课表，再删除旧课表。

### 旧数据会不会丢失

升级后原有课表会自动作为一份课表保存，原课程、日期和节次设置会迁移到这份课表中。

## 验收清单

- [ ] 课表页右上角能看到“切换课表”按钮
- [ ] 能看到当前课表名称和课表列表
- [ ] 切换后课程、周数、日期同步变化
- [ ] 新增课表不会覆盖已有课表
- [ ] 重命名后名称持久化
- [ ] 删除前有确认，且不能删除最后一份课表
- [ ] 重启应用后仍保留上次选择的课表
